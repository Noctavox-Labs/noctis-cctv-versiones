# NOCTIS CCTV — descargas

Programa de **Noctavox Films** para revisar las horas de grabación de las cámaras de seguridad (CCTV) de una investigación de NOCTIS. Marca lo raro (sombras, orbes, destellos, cosas que cambian de lugar, fallas de señal) y deja aparte a las personas del equipo. Todo se analiza en la compu: los videos no salen de ella.

## Descargar

**[Última versión →](https://github.com/Noctavox-Labs/noctis-cctv-versiones/releases/latest)**

- **Windows** (10 y 11, 64 bits): `NOCTIS-CCTV-<versión>-Windows.exe`. Ábralo y siga los pasos. No pide permiso de administrador.
- **Mac** (con chip Apple, macOS 12 o más nuevo): `NOCTIS-CCTV-<versión>-Mac.dmg`. Ábralo y arrastre NOCTIS CCTV a Aplicaciones.

## La primera vez que se abre

- **Mac**: abre directo. La app está firmada por Noctavox y revisada por Apple.
- **Windows**: el programa todavía no lleva firma de Microsoft, así que Windows pregunta una vez. Si muestra «Windows protegió su PC», toque **Más información** y después **Ejecutar de todas formas**.

## Actualizaciones

No hay que volver a esta página: cuando sale una versión nueva, el programa muestra arriba «NOCTIS CCTV x.y.z está lista para instalar» con el botón **Actualizar**. Se instala sola y el programa se vuelve a abrir. Nunca se actualiza durante un análisis.

Cada versión va firmada por Noctavox: el programa solo instala lo que trae esa firma.
